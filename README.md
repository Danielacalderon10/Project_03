# ☕ Coffee Space App

A simple web application where users can **log in** and **book a space** at the café.  
Whether you need a cozy corner for **studying** 📚 or want to join a **lecture club** 🎤, this app makes it easy to reserve your spot.

---

## 🚀 Features
- 🔑 User authentication (sign up / log in)  
- 🗓️ Book a café space for studying or events  
- 👥 Manage personal bookings  
- 📱 Responsive design for desktop  

---

## 🛠️ Tech Stack & Dependencies
- **Backend:** Node.js, Express  
- **Frontend:** HTML, EJS, CSS, JavaScript  
- **Database:** PostgreSQL (via `pg-promise`)  
- **Other dependencies:**  
  - `dotenv` → manage environment variables  
  - `morgan` → HTTP request logging  
  - `axios` → HTTP requests  
  - `ejs` → templating engine  
  - `path` → path utilities  
  - `nodemon` → auto-restart server during development
